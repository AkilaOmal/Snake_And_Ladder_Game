🎲 Snake and Ladder Game (Java + Swing)

A simple **Snake & Ladder** board game built using **Java Swing** for the user interface and **HashMap** for tracking player positions.  
The game includes images, dialog boxes for player notifications, and even a standalone **.exe** file created using **Launch4j**.  
A short gameplay video is also included to demonstrate the game in action!

---

🧠 Overview
This project recreates the classic *Snake & Ladder* board game using pure Java.  
Players roll a dice, move across a 100-cell board, climb ladders, and slide down snakes.  
When a player wins, a **dialog box** pops up displaying the winner.

 🧰 Technologies Used
- ☕ **Java SE**
- 🪟 **Java Swing** for GUI components
- 🧮 **HashMap** for mapping snakes and ladders
- 🖼️ **Images** for board design and player icons
- 💬 **Dialog Boxes (JOptionPane)** for game messages and winner display
- ⚙️ **Launch4j** to create a Windows `.exe` file
- 💻 **IntelliJ IDEA** as the development environment
- 🧾 **Git & GitHub** for version control
